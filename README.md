Premium Resume Builder 🚀
A sleek, dynamic, and professional Resume Builder web application built with Vanilla JavaScript, HTML5, and CSS3. Create stunning resumes with real-time previews and multiple premium templates.

✨ Features
Live Dynamic Preview: See your changes instantly as you type.
4 Premium Templates:
Modern: Dark themed header with a crisp two-column layout.
Minimal: Elegant, typography-focused design for a clean look.
Professional: Classic corporate style optimized for ATS readability.
Creative: Modern, sidebar-based layout with vibrant accents.
Dynamic Sections: Add or remove multiple work experience and education entries dynamically.
Responsive Design: Built using modern CSS Grid and Flexbox for a seamless experience.
One-Click PDF Export: Optimized print styles ensure your resume looks perfect when saved as a PDF or printed.
Rich UI: Powered by Lucide icons and Google Fonts (Inter, Outfit, Playfair Display).
🛠️ Tech Stack
Frontend: HTML5, CSS3 (Vanilla), JavaScript (Vanilla)
Icons: Lucide Icons
Fonts: Google Fonts
🚀 Getting Started
Since this project is built with Vanilla technologies, there is no setup or installation required!

Open the Project Simply open the index.html file in any modern web browser:

Windows: Double-click index.html or run start index.html in PowerShell.
Mac/Linux: Run open index.html or xdg-open index.html.
